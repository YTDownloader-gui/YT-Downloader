## FAQ


**nightly?**
Stable pin is 2026.08.19. `yt-dlp --update-to nightly` if a site breaks.

**ffmpeg?**
Needed to merge video+audio. Drop `ffmpeg.exe` next to yt-dlp.

## Requirements
Windows 10/11 x64. ffmpeg recommended.
